[ LEGEND ]
CRC Type:    Dyn = Calculate using CRC-16-CCITT over bytes [0-15]
             Hard = Use hardcoded lookup table (DO NOT calculate)

Response:    Status = Poll 0x0200 until busy bit clears
             Byte[4] = Read byte from response[4] after polling
             N bytes = Read multi-byte response from 0x1d00

⚠ Warning:   Ambiguity exists, verify against actual camera behavior
* Multi-byte: Use little-endian encoding (LSB first)

Parameters:  P1=byte[4], P2=byte[5], ... P12=byte[15]
             Unused params must be 0x00

---

[ PACKET STRUCTURE - STANDARD 18-BYTE ]
Byte   Field      Example
[0]    Class      0x10 (camera), 0x01 (device/zoom)
[1]    Module     0x02-0x31 (varies)
[2]    SubCmd     0x40-0x8F (varies)
[3]    Reserved   Always 0x00
[4-15] P1-P12     Parameters (varies, unused=0x00)
[16]   CRC_Low    LSB of CRC-16-CCITT
[17]   CRC_High   MSB of CRC-16-CCITT

[ USAGE EXAMPLES ]

Set Brightness to 50:
  Packet: 10 04 47 00 32 00 00 00 00 00 00 00 00 00 00 00 [CRC_L] [CRC_H]
  CSV Ref: Row 167
  CRC: Dynamic (calculate over bytes 0-15)

Set Output Mode to TNR (Mode 2):
  Packet: 10 10 45 00 02 00 00 00 00 00 00 00 00 00 00 00 11 C6
  CSV Ref: Row 97
  CRC: Hardcoded (0x11, 0xC6) - DO NOT calculate

Set Zoom to 2x:
  Packet: 01 31 42 00 00 14 00 00 00 00 00 00 00 00 00 00 [CRC_L] [CRC_H]
  CSV Ref: Row 119
  Note: P2 = level × 10 (2×10=20=0x14)
  CRC: Dynamic

Get Device Name:
  Packet: 01 01 81 00 01 00 00 00 00 00 00 00 20 00 00 00 FC 1E
  CSV Ref: Row 56
  CRC: Hardcoded (0xFC, 0x1E)
  Response: 40-byte ASCII string

[ EXECUTION STEPS ]
1. Construct 18-byte packet with correct class/module/subCmd
2. Insert parameters at correct positions (P1=byte[4], P2=byte[5], etc.)
3. Set unused parameter bytes to 0x00
4. Calculate CRC (dynamic) or lookup CRC (hardcoded)
5. Append CRC at bytes [16]=LSB, [17]=MSB
6. Write packet to I2C register 0x1d00
7. Poll I2C register 0x0200 every N ms until busy bit clears
8. Check error bit (bit 1): 0=success, 1=failure
9. If GET command, read response from 0x1d00

[ COMMON MISTAKES ]
❌ Sending 0x55/0x43/0x49 (SERIAL protocol) to I2C bus
✅ Use 0x10/0x10/0x45 for output mode on I2C

❌ Setting zoom P2=2 for 2x zoom
✅ Set zoom P2=20 (level × 10)

❌ Calculating CRC for output mode/device info
✅ Use hardcoded CRC from lookup tables above

❌ Using big-endian for multi-byte parameters
✅ Use little-endian (LSB first, MSB second)

❌ Forgetting P9=0x01 on GET commands
✅ Always set P9=0x01 for GET commands
